# 正则表达式学习理解

> 正则表达式是程序员的文本处理利器，掌握它能让你的开发效率翻倍！

## 一、什么是正则表达式？

正则表达式（Regular Expression，简称 regex）是一种强大的**字符串处理工具**，它使用特定语法规则来描述字符串的模式。主要用途包括：

- ✅ **字符串匹配** - 检查字符串是否符合特定模式
- ✅ **文本替换** - 批量修改字符串内容  
- ✅ **信息提取** - 从文本中提取特定内容
- ✅ **数据验证** - 验证用户输入的格式是否正确

## 二、核心概念详解

### 1. 字符与元字符

**普通字符**：直接匹配自身的字符，如字母 `a`、数字 `5`、符号 `@`

**元字符**：具有特殊功能的符号：

| 元字符 | 功能说明 | 示例 |
|--------|----------|------|
| `.` | 匹配任意单个字符（除换行符） | `a.c` 匹配 "abc"、"a c" |
| `*` | 匹配前一个字符0次或多次 | `ab*c` 匹配 "ac"、"abc"、"abbc" |
| `+` | 匹配前一个字符1次或多次 | `ab+c` 匹配 "abc"、"abbc" |
| `?` | 匹配前一个字符0次或1次 | `ab?c` 匹配 "ac"、"abc" |
| `^` 和 `$` | 匹配字符串的开头和结尾 | `^abc` 匹配以abc开头的字符串 |
| `\b` 和 `\B` | 匹配单词边界和非单词边界 | `\bword\b` 匹配独立单词"word" |
| `[]` | 字符集合 | `[0-9]` 匹配任意数字 |
| `()` | 分组，用于捕获子表达式 | `(abc)+` 匹配 "abc"、"abcabc" |

### 2. 量词

量词用于指定字符出现的次数：

| 量词 | 说明 | 等价写法 |
|------|------|----------|
| `{n}` | 精确匹配n次 | - |
| `{n,}` | 至少匹配n次 | - |
| `{n,m}` | 匹配n到m次 | - |
| `*` | 0次或多次 | `{0,}` |
| `+` | 1次或多次 | `{1,}` |
| `?` | 0次或1次 | `{0,1}` |

### 3. 字符类

预定义的字符集合，简化常见模式的匹配：

| 字符类 | 说明 | 等价写法 |
|--------|------|----------|
| `\d` | 匹配数字 | `[0-9]` |
| `\w` | 匹配字母、数字、下划线 | `[a-zA-Z0-9_]` |
| `\s` | 匹配空白字符 | `[ \t\n\r\f\v]` |
| `\D` | 匹配非数字 | `[^0-9]` |
| `\W` | 匹配非字母数字下划线 | `[^a-zA-Z0-9_]` |
| `\S` | 匹配非空白字符 | `[^ \t\n\r\f\v]` |

### 4. 修饰符

修饰符改变正则表达式的匹配方式：

| 修饰符 | 说明 | 示例 |
|--------|------|------|
| `i` | 忽略大小写 | `/abc/i` 匹配 "ABC"、"AbC" |
| `g` | 全局匹配 | 匹配所有符合条件的内容 |
| `m` | 多行模式 | `^` 和 `$` 匹配每行的开头结尾 |

## 三、实战应用示例

### 1. 数据验证

数据验证是正则表达式最常见的应用场景。

#### 📧 邮箱验证

**正则规则**：
^\w+([-+.]\w+)*@\w+([-.]\w+)*\.\w+([-.]\w+)*$

**规则解析**：
- `^` 和 `$` - 确保匹配整个字符串，防止部分匹配
- `\w+` - 匹配邮箱用户名的第一个字符（字母、数字、下划线）
- `([-+.]\w+)*` - 允许出现0次或多次的"符号+字符"组合
- `@` - 严格匹配@符号
- `\w+([-.]\w+)*` - 匹配域名部分（如"example"、"sub-example"）
- `\.\w+([-.]\w+)*` - 匹配顶级域名（如".com"、".co.uk"）

**支持的格式**：
- `user@example.com`
- `user.name@example.com`
- `user+tag@example.co.uk`
- `user-name@sub.example.com`

#### 📱 手机号验证（中国大陆）

**正则规则**：
^1[3-9]\d{9}$

**规则解析**：
- `^1` - 必须以1开头
- `[3-9]` - 第二位必须是3-9（覆盖移动、联通、电信等运营商）
- `\d{9}` - 后面9位任意数字
- 总共11位数字

**支持的号段**：
- 移动：134-139, 147, 150-152, 157-159, 178, 182-184, 187-188
- 联通：130-132, 145, 155-156, 166, 171, 175-176, 185-186
- 电信：133, 149, 153, 173, 177, 180-181, 189, 199

### 2. 信息提取

从文本中精准提取所需信息，适用于日志分析、数据抓取等场景。

#### 🪪 身份证号提取（中国大陆）

**正则规则**：
[1-9]\d{5}(19|20)\d{2}(0[1-9]|1[0-2])(0[1-9]|[1-2]\d|3[0-1])\d{3}[\dXx]

**规则解析**：
- `[1-9]\d{5}` - 前6位地区码（第一位不能为0）
- `(19|20)\d{2}` - 年份（1900-2099）
- `(0[1-9]|1[0-2])` - 月份（01-12）
- `(0[1-9]|[1-2]\d|3[0-1])` - 日期（01-31，考虑月份天数）
- `\d{3}` - 顺序码
- `[\dXx]` - 校验码（数字或X）

**提取示例**：
```java
// 从文本中提取所有身份证号
String text = "用户信息：张三，110101199003077635；李四，440101198510201234X";
Pattern pattern = Pattern.compile("[1-9]\\d{5}(19|20)\\d{2}(0[1-9]|1[0-2])(0[1-9]|[1-2]\\d|3[0-1])\\d{3}[\\dXx]");
Matcher matcher = pattern.matcher(text);
while (matcher.find()) {
    System.out.println("找到身份证: " + matcher.group());
}
// 输出: 
// 找到身份证: 110101199003077635
// 找到身份证: 440101198510201234X
```

### 3.文本替换

批量修改文本内容，如数据清洗，格式化输出

#### 隐藏手机号中间四位

**正则规则**：
(\\d{3})\\d{4}(\\d{4}) → \$1\*\*\*\*\$2

**规则解析**：
- 用分组()保留前3位和后4位
- 中间4位替换为\*\*\*\*，实现隐私脱敏
